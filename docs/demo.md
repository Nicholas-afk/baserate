# Final-release demonstration

[Watch the demo on YouTube](https://www.youtube.com/watch?v=h_tE2tU72ek) · [Download the project files](https://nicholas-afk.github.io/baserate/project.html).

The 109.4-second, 16:9 demo uses the entrant's supplied recording with the source interval 52.995–55.595 seconds removed; no words are synthesized or rearranged. The source waveform remains unchanged and private. Level gain and a peak limiter are applied to the delivered audio. No music or generated voice is included.

All application pixels come from genuine browser interactions with the final public app. The edit uses cropped screen-state captures, holds and hard cuts, rather than a continuous screen recording. There is no rebuilt interface or invented cursor. The walkthrough's estimates (90%, 80%, 50%) are staged demonstration inputs, not learner-study observations. All three cases were actually completed and the notebook export control was used.

## Narration qualifications

- **“29 of 30 separate synthetic examples”** means the raw result on the unchanged same-project synthetic holdout. The splits contain no exact duplicate sentences but share authorship, task and familiar claim patterns. On screen: 28 accepted labels, 27 correct. These are development checks, not an independent benchmark or proof of learning.
- **Coach feedback** proposes a review topic. It can misread a correct explanation. The factual check verifies only the selected option; it does not verify the explanation, diagnose a misconception or grade competence.
- **“The words stay in the browser”** describes the application's local inference and tab memory. Static app/model/media requests still contact GitHub Pages. A connected browser assistant has separate data handling.
- **Educational value** is an intended use. No learner study, clinical validation or measured health benefit has been completed.
- **Editing** removes one repetitive clause from the original recording. The original file remains private and unchanged. Short editorial annotations are not presented as verbatim captions.
